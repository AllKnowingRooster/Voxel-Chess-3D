# Intro
Single Player And Multi Player 3D Chess using voxel asset.

Currently Multiplayer only work for local games/ LAN( I am working on Online Play world wide)

# How to Start Game
1.go to /build and run Voxel-Chess-3D.exe

# How to Play
1.Just Drag chess Piece onto the highlighted square(green = Move , red=Attack) 

# you lose when
1.timer runout

2.checkmate

# draw when
1.Stalemate(you or opponent cannot make a move but king is not checked)
