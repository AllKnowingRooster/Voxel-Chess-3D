Single Player And Multi Player 3D Chess using voxel asset.

Currently Multiplayer only work for local games/ LAN( I am working on Online Play world wide)

How to Start Game:
go to /build and run VoxelChess3D.exe

How to Play:
-Just Drag chess Piece onto the highlighted square(green = Move , red=Attack) 

you lose when:
-timer runout
-checkmate

draw when:
-Stalemate(you or opponent cannot make a move but their king is not checked)
